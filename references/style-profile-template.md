# 版式风格 profile（无原图时用这一份）

> 有论文原图时，一切以原图为准；**这一份是"没有原图、要从 0 生成"时的默认值**。
> 下面的数字不是拍脑袋定的：是从 Cu-MAZ 论文正文 Fig.5 / Fig.6 / Fig.1 和 SI Fig.S7 的原图像素反推出来的
> （见文末"标定记录"）。换期刊/换组时，拿目标期刊的成图重做一次标定，改这张表，不要改流程。

## 0. 先定画布，再定字号

字号偏小是这类返工最常见的失败点（Cu-MAZ Fig5 第一版字号只有原图的 0.5–0.7），根因几乎都是
**画布画大了、字号没跟着放大**。所以顺序固定：

1. 选画布宽度（下面有建议值）；
2. 用"目标比例"反算字号；
3. 出图后量一遍（`scripts/style_fingerprint.py`），不达标就改字号，不要改画布凑。

**换算公式**

```
pt = target_ratio × 图高(in) × 72 / k

k 的取值（Times New Roman Bold，实测）：
  刻度数字（cap 高）           k ≈ 0.66
  轴标题（含括号，整体高度）    k ≈ 0.88
  图例整行（含下标下伸）        k ≈ 0.84
  S1/S2 之类标注（cap 高）      k ≈ 0.66
```

例：8 in 宽、3.578 in 高的双面板图，刻度目标 3.17% 图高
→ `0.0317 × 3.578 × 72 / 0.66 = 12.4 pt` → 用 12.5 pt。

## 1. 画布

| 图型 | 建议宽 | 高 | 说明 |
|---|---|---|---|
| 正文双面板（A/B，如 EPR+TPR） | 8.0 in | 按原图宽高比 | Cu-MAZ Fig5 = 8.0 × 3.578（2400×1074 @300 dpi） |
| 正文大拼图（2×2，如 Fig1/Fig6） | 8–10 in | 按宽高比 | 不要超过 12 in，否则 12 pt 字号会显得很小 |
| SI 单面板（如 UV-Vis） | 7–8 in | 按宽高比 | 单面板不要用 5 in 以下，字会挤 |

画布定下来后，**先算出各字号，再写代码**。绝对 pt 值本身没有意义，比例才有意义。

## 2. 字号与元素比例（占"图高"或"面板高"的百分比）

| 元素 | 目标比例 | 8×3.578 in 双面板上的对应 pt | 备注 |
|---|---|---|---|
| 轴标题（Field (G) / Temperature (°C)） | **5.9–6.0% 图高** | 17.5 | 含括号的总高度 |
| 刻度数字 | **3.1–3.4% 图高** | 12.5 | 数字 cap 高；原图里它和轴标题接近，别把刻度设得太小 |
| 纵轴标题 | 与横轴标题同号 | 17.5 | 旋转 90°，贴轴放（见下） |
| 图例文字 | **5.3–5.4% 面板高** | 14 | 整行含下标 |
| 图例行距 | 8.4% 面板高 | labelspacing 0.4 | |
| 图例 handle 长 | 6.0% 面板宽 | handlelength ≈ 1.2 | 和字号联动，字号一变要重算 |
| S1–S4 类标注 | **11.6% 面板高** | 12.5 | cap 高 |
| 样品名（面板内右上） | 3.3–3.8% 图高 | 13 | |
| 面板字母 A/B | 4.5% 图高 | 18 | |

**注意**：Origin 出图常见"刻度数字几乎和轴标题一样大"。不要套"标题大、刻度小一半"的网页习惯。

## 3. 边框、刻度、轴

| 项 | 默认 | 说明 |
|---|---|---|
| 边框 | **四边全画** | 除非原图明确去掉上/右 |
| 边框线宽 | 0.33% 图宽 ≈ **1.8 pt**（8 in 画布） | |
| 刻度方向 | **朝外（out）** | 原图多为 out；朝内会被看成"没画刻度" |
| 主轴刻度长 | 2.6 pt（A 面板）/ 3.8 pt（B 面板） | 原图里 A、B 可能不同，逐面板看 |
| 次刻度 | **默认不加** | Fig5 原图 A 面板没有次刻度；加了就是多余 |
| 次刻度长 | 主轴的一半以内（1.9 pt） | |
| 纵轴刻度 | 多为**无刻度、无数字** | 只留轴标题 |

## 4. 填充与线

| 项 | 默认 |
|---|---|
| 分峰填充 | **向白垂直渐变**：曲线处 α≈0.9，到基线渐隐到 0；α(t)=0.9·(1−t)^1.15 |
| 分峰轮廓线 | 1.5 pt、**不透明**（半透明线会被平涂背景吃掉） |
| 总拟合线 | 1.8–1.9 pt、样品色 |
| 观察值线 | 1.5 pt、#8C8C8C–#9A9A9A 灰，压在总拟合线下方 |
| 对比色 | 用作者配色；不要自己改成 matplotlib 默认色环 |

平涂（统一 α）会把重叠区叠成发褐的脏色，这是 Fig5 第一版最明显的"假"。

## 5. 标注（S1–S4、分峰归属）

- 分峰标注**只标在顶部子图**，其余子图不重复标（原图如此，也避免拥挤）。
- 引线几何：**底端 = 该分峰峰顶，顶端 = 该 x 处总拟合线以上 3% 面板高**；标签浮在引线顶端。
- 特例：如果该峰的顶端已经贴着面板顶（如 S1），标签放在**引线下方**（峰顶下方约 4% 面板高）。
- 引线 1.3 pt、黑色、solid_capstyle="butt"，不要带箭头。
- 引线 x 用**作者报告的峰位**，不要用你目测的峰顶。

## 6. 面板与边距

| 项 | 默认 |
|---|---|
| 左边距 | 3.9% 图宽 |
| 右边距 | ≤1% 图宽 |
| 上边距 | 面板框顶到画布顶 ≈0.9% 图高（墨迹 ≥0.2%，边框不要被裁） |
| 下边距 | 13.8% 图高（刻度 + 轴标题） |
| 面板间距 | 6% 图宽 |
| 多子图堆叠 | hspace=0，相邻边框重合，只出现一条分隔线 |

**轴标题不要用 set_xlabel(labelpad=...) 堆**：字号一大就会被 bbox 堆叠顶出画布。
用 fig.text 放在量好的位置（见 plot-recipes.md）。
