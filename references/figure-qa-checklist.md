# 版式几何验收清单

这张清单来自 Cu-MAZ 的实际返工，专门防止"数据对了但版式又错"的重复问题。

**两条路径，先选一条：**

- **A. 有论文原图** → 逐项对照原图；原图就是验收标准。
- **B. 没有原图、要从 0 生成** → 用 references/style-profile-template.md 的默认比例；验收标准是"比例落在表内"。
  这种情况下最容易翻车的是**字号/画布比例**，不是配色。

量的时候用 `scripts/style_fingerprint.py`：
```
python scripts/style_fingerprint.py 新图.png                    # B 路径：对照 house style
python scripts/style_fingerprint.py 新图.png --ref 原图.png      # A 路径：两列对比
```

---

## 0. 先定比例，再写代码

- 画布多大？(见 style profile §1)
- 轴标题、刻度、图例、标注各多少 pt？——**先按比例算出来**，不要先写完代码再"看着调"。
- 比例公式：`pt = 目标比例 × 图高(in) × 72 / k`，k 见 style profile §0。
- 检验：出图后量"刻度数字带宽 / 图高"和"轴标题带宽 / 图高"，必须在 3.1–3.4% 和 5.7–6.2%。

> Cu-MAZ Fig5 第一版的翻车点就在这里：画布 10 in、字号没跟着放大，刻度只有原图的 0.50、图例 0.70。
> 数据全对，但整张图"小一号"。

## 1. 有原图时：先看图，再写代码

- 图例在面板内还是面板外？几列几行？第三/第四个条目在哪个位置？
- 图例左对齐、居中还是贴右？
- 面板标题是独立文字，还是图例里的一个条目？
- `//` 断口出现在哪些面板？A/C/D 都要看，不要只改第一个。
- 横轴标题离刻度多远？**先量原图**（下边距 %），不要拍脑袋。
- 误差棒到底有没有？原图没有就不要自己加。
- **刻度方向朝内还是朝外？长度多少？有没有次刻度？**（逐面板量：Fig5 原图 A 面板没有次刻度，B 面板有）

## 2. 图例

- 用 Line2D 自定义 handle（line + marker），不要用 errorbar 的 handle；否则图例会带上下帽。
  有过一例：S1 图重画后图例又变回 errorbar handle——**这条要每次查**。
- Matplotlib legend **按列填充**。要视觉行优先，需重排 handles。
  - 例：想要 `row1: A, B; row2: C, D`，handles 顺序应为 `A, C, B, D`（ncol=2）。
- 说明文字（如 `NH3 · 60 min`）放在图例第二行右列时，用**不可见 dummy handle** 占位，不要另写 `ax.text`。
- 面板内图例用 `loc` + `bbox_to_anchor`；贴右边 `loc="upper right", bbox_to_anchor=(1.0, 1.0), borderaxespad=0`。
- 图标/说明文字要和图例**文字左缘**对齐：用 `legend.texts[0].get_window_extent(renderer)` 反算，不硬编码 x。
- **图例顺序**按原图从上到下；handle 长度随字号变，改字号后必须重测（6% 面板宽）。
- 图例不能压住峰位标注/曲线；出图后 100% 放大检查。

## 3. 误差棒

- 只在原图有 error bar 时画；没有就 `plot`，不要 `errorbar`。
- SD/SE 仍保留在 CSV/QA 里，不能因为不画就丢掉。
- 如果原图有误差棒但当前只有 SD，标明是 SD 还是独立重复误差。

## 4. broken axis 的 `//`

- 每个 broken panel 都要有断口标记；**列出所有 panel**，不要漏 D。
- 不要用 axes 坐标画，左右 axes 的宽高比不同，斜率会不平行。
- 用 figure 坐标，两侧同一个 `dx/dy`（`scripts/figure_geometry.py: break_marks`）。
- 每个断口上下各一个；检查左右是否同斜率。
- **没断轴的图不要加 `//`**（Fig5 就没有）。

## 5. 轴标题距离

- 不要用 `set_xlabel(labelpad=…)` 堆：字号一大就被 bbox 顶出画布（Fig5 v2 第一版整行被裁）。
- 用 `fig.text(x, y, …, va="baseline")` 放在量好的位置；y 从原图的下边距反算。
- 用 `fig.text` 时要检查底行是否被裁剪；底行面板的标题要留出 footer 空间。
- 竖直方向同理：纵轴标题用 `fig.text(rotation=90, ha/va="center")` 贴在轴边，距离 ≤1.5% 面板宽。

## 6. 填充与线

- 分峰填充是**平涂还是渐变**？原图多为"向白垂直渐变"，平涂会把重叠区叠成脏色。
- 轮廓线是不透明还是半透明？半透明线配平涂底色会"消失"。
- 总拟合线、观察值灰线的线宽和灰度，逐条量。
- 渐变实现见 `references/plot-recipes.md` 第 1 节。

## 7. 标注（S1–S4、分峰归属）

- 只标在最上面那个子图？还是每个子图都标？
- 引线的底端在分峰峰顶还是别处？顶端到哪？标签在引线上方还是下方？
- 引线 x 用作者报告的峰位，不要目测。
- 量的时候记"引线 y 起止 / 标签 y 起止"四个数（占子图高的分数），复测时逐条对。

## 8. 数据冲突

- 源表与原图不一致时，**不要按图猜数**。
- 记录源文件的 mean/SD/n/blocks；在图上/图注/QA 标出冲突。
- 只有作者确认后才能改数据；不要用"看起来像"覆盖源值。

## 9. 出图后检查

- 打开 PNG 100% 看，不只看代码没报错。
- 对照原图逐项：图例位置/顺序、面板标题、峰位标注、`//`、轴标题距离、误差棒、曲线颜色、刻度方向。
- 每个 panel 都看；A 对了不代表 D 对。
- 图注/PPT 里的描述要和最终图一致。

## 10. 最小回归

改完一张图后，至少回归：

- 同一图的 A/B/C/D 四个 panel；
- 图例贴近边缘时是否被裁；
- `//` 是否左右平行；
- 横轴标题是否贴轴、是否被裁；
- **字号比例是否落在 style profile 的区间内**；
- 与上一版对比，确认没把已修的问题带回来。

## 11. 无原图时（B 路径）额外要过的一关

- 换一台机器/换一次导出，重跑 `style_fingerprint.py`，确认比例没漂。
- 把这次实际用的字号/线宽/边距写进该论文的 case profile §5，下次改图沿用，不要再重新拍。
